# Установка скилла

## Папка скиллов

Своя у каждого агента (по его документации); примеры:

| Агент | Папка скиллов |
|---|---|
| Claude Code | `~/.claude/skills` (Windows: `%USERPROFILE%\.claude\skills`) |
| Kimi Code | `~/.kimi-code/skills` — не проверено |

Эти пути — только здесь; в `SKILL.md` и коде наборов их нет (00).

## Клон и настройка

Сначала skill-skill (общие проверки, хук, стоп-лист), потом наборы:

```bash
cd "<папка скиллов>"
git clone https://github.com/RungeKut/Skill-Skill.git skill-skill
git -C skill-skill config core.hooksPath hooks
git clone https://github.com/RungeKut/<Имя>-Skill.git <name>   # имя папки = name в SKILL.md
cd <name>
git config core.hooksPath ../skill-skill/hooks   # общий хук commit-msg
git config user.name  "<публичное имя>"          # автор — для клона (40-02)
git config user.email "<публичный адрес>"
python tools/check_docs.py                       # до «Расхождений нет»
```

То же `git config user.*` — в skill-skill. Хук, автор и стоп-лист **не
клонируются**: на каждой машине — заново, `check_docs.py` напомнит.

**Стоп-лист** — `skill-skill/tools/stoplist.txt`, общий для всех наборов
машины, локальный (в `.gitignore`), строка — слово или фраза, `#` —
комментарий. У набора может быть свой `tools/stoplist.txt` — проверки
берут объединение. Новая машина — завести пустым и вписать приметы своих
проектов до первого коммита (40-02).

**Python для хука** — настоящий, не заглушка Microsoft Store (30-02):
каталог Python в PATH оболочки, из которой вызывается git.

## Несколько агентов

По клону в папку скиллов каждого агента; клоны сходятся только через
GitHub — после правки в одном push, в другом pull (не проверено, как
агенты делят одну папку).

## Обновление

`git pull --rebase` в клоне. Claude Code подхватывает правку `SKILL.md` и
новые скиллы без перезапуска (проверено на hidden-desktop); смена `name`
на лету и другие агенты — не проверено. Обновление общих правил и проверок
во всех наборах разом — `git pull` в skill-skill.

## Новый скилл

```bash
python skill-skill/tools/new_skill.py <name> <Имя>-Skill
```

Копирует `templates/skill`, делает `git init -b main`, хук, автора (как у
клона skill-skill), origin `https://github.com/RungeKut/<Имя>-Skill.git`,
пустой стоп-лист. Репозиторий на GitHub заводит владелец (40-03).

## Подключение соседнего набора из кода

```python
ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
sys.path.insert(0, os.path.join(os.path.dirname(ROOT), "<name соседа>"))
```

Глубину `dirname` — по месту файла в наборе. Переменные окружения не
читать (30-01).
