# Skill-Skill

Корень — папка этого файла (клон `RungeKut/Skill-Skill`). Соседние скиллы
— папки рядом; у каждого `SKILL.md` в корне, имя папки = `name`. Закон базы
для всех наборов — `knowledge/00_ПРАВИЛА.md`, карта — `knowledge/INDEX.md`.

**Первым делом:** `git -C <корень> pull --rebase` здесь и в наборе, который
правите; конфликт — разобрать до работы (40-02).

```bash
python <корень>/tools/check_docs.py --root <скилл> [--project <папка>]
python <корень>/tools/check_all.py [-v]          # все соседи, сводка
python <корень>/tools/new_skill.py <name> <Имя>-Skill
```

В наборе `python tools/check_docs.py` — обёртка, вызывает общую.

**Порядок правки:** правка → `git diff` глазами → `check_docs.py --project
"<папка проекта>"` → `git add <файлы>` → `git commit` → `git push` сразу.
Шаг = коммит; amend — только неотправленного; после pull — проверку
заново и перечитать слитое.

## Железные правила

1. В набор, коммит и PR — ничего о рабочих проектах: изделия, файлы, пути,
   серверы, учётки, имена, снимки окон рабочих программ. Новое — строка в
   локальный стоп-лист до первого коммита (40-02).
2. Без соавторов: ни `строка соавторства`, ни «Generated with», ни 🤖, ни
   noreply-адресов ИИ (30-04).
3. Автор — публичное имя, заданное для клона (`git config user.*` без
   `--global`); не задан — не коммитить, спросить человека.
4. В `SKILL.md` и коде — ни путей агента, ни переменных окружения: корень
   — папка `SKILL.md`, сосед — `<родитель корня>/<name>` (30-01).
5. `SKILL.md` ≤ 4096 байт, `description` ≤ 1024 знаков в кавычках;
   подробности — в базу (00, 30-06).
6. PR сливает только владелец: `fetch pull/<N>/head` → проверка →
   `merge --no-ff` → push; без squash и rebase (40-02, 30-03).
7. Удаление, перепись истории, `push --force` — по команде человека.
8. Общее правило меняется здесь; в наборе — только своё и строка «общие
   правила — соседний скилл skill-skill».

Установка, хук, стоп-лист — 40-01; GitHub без gh — 40-03.
