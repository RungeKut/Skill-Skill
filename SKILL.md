# Skill-Skill

Корень — папка этого файла (клон `RungeKut/Skill-Skill`). Соседние скиллы
— папки рядом; у каждого `SKILL.md` в корне, имя папки = `name`. Закон базы
для всех наборов — `knowledge/00_ПРАВИЛА.md`, карта — `knowledge/INDEX.md`.

**Первым делом:** `git -C <корень> pull --rebase` здесь и в правимом
наборе; конфликт — разобрать до работы (40-02). Из корня:

```bash
python tools/check_docs.py --root <скилл> [--project <папка>]
python tools/check_all.py [-v]
python tools/new_skill.py <name> <Имя>-Skill
```

В наборе `python tools/check_docs.py` — обёртка, вызывает общую.

**Порядок правки:** правка → `git diff` глазами → `check_docs.py --project
"<папка проекта>"` → `git add <файлы>` → `git commit` → `git push` сразу.
Шаг = коммит; amend — только неотправленного; после pull — проверку
заново и перечитать слитое.

## Железные правила

1. В набор, коммит и PR — ничего о рабочих проектах: изделия, пути,
   серверы, учётки, имена, снимки окон. Новое — в локальный стоп-лист до
   первого коммита (40-02).
2. Без соавторов и подписей ИИ в коммите и PR (30-04).
3. Автор — публичное имя в `git config user.*` клона (не `--global`); не
   задан — не коммитить, спросить человека.
4. Ни путей агента, ни переменных и путей для поиска наборов: корень —
   папка `SKILL.md`, сосед — `<родитель корня>/<name>` (30-01). Настройки
   внешних программ — необязательные, с умолчанием (40-01 набора).
5. `SKILL.md` ≤ 2400 знаков (≈ 1024 токена), `description` ≤ 1024 в
   кавычках; формат `name` — 00 (30-06).
6. PR сливает только владелец: `fetch pull/<N>/head` → проверка →
   `merge --no-ff` → push (40-02, 30-03).
7. Удаление, перепись истории, `push --force` — по команде человека.
8. Общее правило меняется здесь; в наборе — только своё и строка про
   skill-skill.
9. Подпись ИИ выключить в источнике: Claude Code — `attribution` в его
   настройках; на GitHub — без squash и rebase (40-04).

Установка, хук, стоп-лист — 40-01; GitHub без gh — 40-03.
