* Общие правила семи наборов собраны в одном скилле: закон базы
  (`00_ПРАВИЛА.md`), установка (40-01), работа с репозиторием (40-02),
  GitHub без gh (40-03), общие грабли 30-01…30-06. Раньше каждый набор
  держал свою копию, и копии расходились.

  `tools/kit_local.py`): к прежним проверкам добавлены история коммитов
  (соавторы, автор и коммитер, стоп-слова), остатки старой установки в
  коде, изображения вне `examples/`, ветка `main`, origin `*-Skill`,
  совпадение обёртки с шаблоном. `check_msg.py`, `check_all.py`,
  `new_skill.py`, шаблон `templates/skill`.
* Общий хук `hooks/commit-msg`: Python ищется по реальному запуску (не
  заглушка Microsoft Store); не найден — коммит отклоняется, а не
  пропускается молча.
* Общий стоп-лист машины — `tools/stoplist.txt`, локальный.
