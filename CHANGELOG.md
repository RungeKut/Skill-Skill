# Журнал изменений

Формат: дата — что изменилось — почему.

## 2026-10-28 — Skill-Skill 0.2.0

Недочёты, найденные при переводе наборов.

* Предел `SKILL.md` — 2400 знаков вместо 4096 байт: владелец задал ≈ 1024
  токена, а 4096 байт русского текста — до ~1200. Все наборы сокращены за
  счёт повторов общих правил.
* Новый репозиторий — открытым (40-03): правило «закрытым» попало из двух
  наборов без решения владельца. Абзац о переезде из 40-02 убран —
  репозитории `*-Skill` созданы.
* Подпись ИИ выключается в источнике — правило 9, запись 40-04: Claude
  Code (`attribution` в настройках пользователя), на GitHub — без squash и
  rebase. Хук и проверка ищут любую строку-подпись `…-by:` вместо одного
  слова: так в правилах и коде нет самого слова.
* `check_docs.py`, история: стоп-слова ищутся и в содержимом всех коммитов
  (имена и добавленные строки, `git log --all -p`) — с коммитом и файлом,
  слово в отчёте — первой буквой и длиной. Раньше видны были только
  сообщения, а утечки жили в старых версиях файлов.
* `check_docs.py`: `.gitattributes` и `LICENSE` в корне; заголовок таблицы
  `INDEX.md`; `name` — 1–64 знака, строчная латиница, цифры, дефис
  (opencode иначе скилл не грузит); `*_HOME` ловится и в `%…%`, `${…}`,
  длинных именах; жёсткие пути `X:\…\skills\…`. Нет `origin/main` —
  «удалённой ветки main нет (репозиторий не создан или не отправлен)»
  вместо «неотправлены все N».
* Переменные окружения: запрещены только для поиска наборов; необязательные
  настройки внешних программ разрешены, с умолчанием и описанием в 40-01
  набора (00, 30-01, 40-01, `SKILL.md`, шаблон 40-01).
* В 00 из SolidWorks-Skill перенесены общие правила: «История» при смене
  поведения, три случая удаления и «устарело», «дубликат хуже пробела»,
  обезличивание отдельным шагом, знание о коде — в docstring.
* В 40-02: стоп-лист не хранить в облаке; таблица того, чего проверка не
  видит; `403` на слияние PR через API — вы не владелец.
* Хук: отказ без Python называет причину и решение, ссылается на 30-02;
  в 30-02 — PATH пользователя и новые терминалы.

## 2026-10-28 — Skill-Skill 0.1.0

* Общие правила семи наборов собраны в одном скилле: закон базы
  (`00_ПРАВИЛА.md`), установка (40-01), работа с репозиторием (40-02),
  GitHub без gh (40-03), общие грабли 30-01…30-06. Раньше каждый набор
  держал свою копию, и копии расходились.
* Общая `tools/check_docs.py` (`--root`, `--project`, особое набора — в его
  `tools/kit_local.py`): к прежним проверкам добавлены история коммитов
  (соавторы, автор и коммитер, стоп-слова), остатки старой установки в
  коде, изображения вне `examples/`, ветка `main`, origin `*-Skill`,
  совпадение обёртки с шаблоном. `check_msg.py`, `check_all.py`,
  `new_skill.py`, шаблон `templates/skill`.
* Общий хук `hooks/commit-msg`: Python ищется по реальному запуску (не
  заглушка Microsoft Store); не найден — коммит отклоняется, а не
  пропускается молча.
* Общий стоп-лист машины — `tools/stoplist.txt`, локальный.
